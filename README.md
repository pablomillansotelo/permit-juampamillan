# Permit - Sistema de Gestión RBAC

Sistema completo de gestión de permisos basado en roles (RBAC) con backend en Elysia.js y frontend en Next.js.

## 📚 Documentación

Toda la documentación del proyecto se encuentra en la carpeta [`permit-docs/`](./permit-docs/).

### Inicio Rápido

- **Documentación Principal**: [`permit-docs/README_PRINCIPAL.md`](./permit-docs/README_PRINCIPAL.md)
- **Backend**: [`permit-docs/backend/README.md`](./permit-docs/backend/README.md)
- **Frontend**: [`permit-docs/frontend/README.md`](./permit-docs/frontend/README.md)

### Estructura del Proyecto

```
permit-juampamillan/
├── permit-backend/     # Backend API (Elysia.js)
├── permit-frontend/    # Frontend (Next.js)
└── permit-docs/        # Documentación completa
```

## 🚀 Inicio Rápido

### Backend

```bash
cd permit-backend
bun install
bun run dev
```

El backend estará disponible en `http://localhost:8000`

### Frontend

```bash
cd permit-frontend
pnpm install
pnpm dev
```

El frontend estará disponible en `http://localhost:3000`
